# Pokopia Tracker

A web app for tracking habitat construction and Pokémon collection in Pokémon Scarlet/Violet's Pokopia feature.

## Features

- Track 70+ habitats across 6 regions with **Not Started / In Progress / Completed** status
- View materials required for each habitat
- Check off caught Pokémon per habitat with bulk check/clear actions
- Filter by status, category, region, or search by name
- Progress persists automatically via browser localStorage

## Tech Stack

- **React 19** with Vite
- Pure CSS (no framework)
- Google Fonts (Nunito, Space Mono)

## Getting Started

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start dev server |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |

## Regions

- Withered Wastelands
- Bleak Beach
- Rocky Ridges
